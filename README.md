# engenharia-de-software

Repositório utilizado para concentrar as implementações de um projeto da matéria **Engenharia de Software**, onde foi proposta a elaboração de um **sistema Web simples utilizando Flask**.

---

## 📐 Arquitetura

A arquitetura do projeto foi inspirada em um projeto passado como exemplo em aula e posteriormente **adaptado**.

O foco do projeto foi realizar uma **introdução à Arquitetura Web**, e **não** construir um sistema completamente funcional ou seguro.

---

## 🛒 Objetivo do Sistema

O sistema em desenvolvimento serve para realizar o **registro de vendas de um supermercado**, envolvendo:

- **Produtos**
- **Vendas**

---

## 📦 Produtos

Para os produtos, é possível cadastrar:

- Nome  
- Marca  
- Categoria  
- Preço  
- Preço promocional  

Além disso, também é possível:

- Editar produtos  
- Apagar produtos  

---

## 🧾 Vendas

Quanto às vendas, é possível:

- Cadastrar múltiplos produtos  
- Selecionar a quantidade de cada produto  

O **preço total da compra** é calculado com base no preço do produto, **dando preferência ao preço promocional**, caso exista.

Também é possível:

- Apagar vendas  

---

Para rodar o programa, siga as instruções disponibilizadas em **`setup.md`**.
